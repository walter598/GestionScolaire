# Gestion scolaire - Projet ADO.NET

Solution Visual Studio 2022 / .NET 8 / MySQL 8.4 / MySql.Data 8.4.0.

Ordre de démarrage :
1. Exécuter `01_BaseDeDonnees/gestion_scolaire.sql` dans phpMyAdmin après avoir remplacé le mot de passe temporaire.
2. Configurer `GS_DB_PASSWORD` et les autres variables facultatives.
3. Ouvrir `GestionScolaire.sln`.
4. Restaurer NuGet, compiler et choisir l'application Console ou Windows Forms comme projet de démarrage.

Consulter `04_Documentation/` pour les détails et les limites de validation.
